One app. Every layer.

Rhema.ai runs on one website — rhema-ai-web.vercel.app. Paths like /app and /pastor are workspaces inside the same software, not separate products.

Reader (public dictionary)

Start: Home → Tour → public app, or Dictionary to skip.

  • Guest: search words, monthly question, map — no email.
  • Member: Sign in with email to save progress.
  • Feedback: Beta survey (~1 min).

Staff (Layer 3)

Always enter here: /staff — not the public tour.

  • Code sign-in — organizer gives code (e.g. P-0233) + password.
  • Phone demo — Register with phone; code shows on screen (SMS demo).
  • After sign-in you open Staff at /pastor — check-in, tracks, review, alerts.

Hidden layers (same app)

  • Admin — sign in as A-0100 → Admin in Reader app (beta CSV, accounts, map draft).
  • Expert / Faith — hold a word headword for parallel traditions; edits go to human review.
  • Safety — harmful or injection text blocked; crisis check-ins held for a person.
  • QA only — #api=0, /screens (not for public testers).
