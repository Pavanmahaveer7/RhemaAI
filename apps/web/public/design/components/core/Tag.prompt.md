Uppercase label chip — "Used in" tradition labels, concept labels, source-app labels.
```jsx
<Tag tone="hindu">Hindu</Tag><Tag tone="buddhist">Buddhist</Tag><Tag tone="christian">Christian</Tag>
<Tag tone="lamp">New this month</Tag>
<Tag>From ChurchPlanner</Tag>
```
List traditions alphabetically (Buddhist, Christian, Hindu) or in lexicon order — never as a ranking.
