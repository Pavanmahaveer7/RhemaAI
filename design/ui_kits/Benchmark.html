Benchmark

Two guards against “AI says everything passes”.

Running… about 8 minutes.

A. Strict vs. informed heuristic score

Strict = no product context, demo controls included, told to be harsh — but it now gets a layout outline of what is drawn (inputs, buttons, bars, graphics, positions) so it judges what users actually see, not just text. Informed = the same reviewer knows our spec decisions. A big gap on a screen means the pass depends on context — check that screen by hand. Strict is the benchmark to report.

B. Silent-break guard (no AI)

A fingerprint of every screen: title, headings, every button and link label, form fields, and the count of each. The first run saves it as the baseline. Every later run lists what disappeared, appeared or got renamed. Nothing can break silently. Save a new baseline only after you’ve checked a change on purpose.
