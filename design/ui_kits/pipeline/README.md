# Pipeline UI kit
L3 pastor pipeline. "View as" switches Pastor / Reviewer.
- Pastor: `PastorHome` (stage path, pack status, check-in prompt, history), `PastorTracks` (Training / Ministry / Character — rows from ChurchPlanner labelled), `PastorPack` (Report, Feedback, Community + Evidence tabs, missing pieces named), `PastorCheckin` (mood, prayed, visits, struggles, wins → pending → plain result).
- Reviewer: `ReviewerQueue` (escalations & incomplete first, then oldest), `ReviewerReview` (agent summary beside human decision; Continue moves the stage marker).
No scores or risk words on pastor screens.
