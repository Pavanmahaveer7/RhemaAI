Flat content container with optional eyebrow/title/action header.
```jsx
<Card eyebrow="1 · Parallel" title="An analogy, not identity">…</Card>
<Card tone="lamp" eyebrow="Faith mode">This compares traditions. It does not replace the definition.</Card>
```
Tones: default, raised, lamp (use lamp only for the Faith-mode notice or "new" highlights).
