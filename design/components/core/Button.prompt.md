Pill-shaped action button; use primary for the main action, accent (Lamp) at most once per screen.
```jsx
<Button icon="search">Search</Button>
<Button variant="accent" size="lg" fullWidth>Submit answer</Button>
<Button variant="secondary" iconRight="arrow-right">Open faith mode</Button>
```
Variants: primary, accent, secondary (outlined), ghost, danger. Sizes sm/md/lg. `loading` swaps the icon for a spinner.
